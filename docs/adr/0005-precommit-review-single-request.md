# 提交前审查使用单次请求

状态：已确认，2026-10-15。

## 决策

- 提交信息是可选的审查意图；为空时仍可审查。执行「审查并提交」时，若提交信息为空，在最终确认后提示填写。
- 每次审查只发送一次模型请求，不自动读取或请求未选择文件的 BASE 上下文。模型应基于所选变更和随请求提供的文本报告问题；证据不足时跳过该候选问题并继续审查。
- 必需提交依赖仍属于实际提交选择，文本变更仍进入审查输入，但结果不单独列出依赖清单。
- 二进制内容不发送给模型，结果不暴露二进制文件清单。若选择中包含不能文本分析的项目，结果仍标记为不完整。

## 原因

减少审查前置要求和额外模型往返，让审查在没有提交意图或未选文件上下文时也能完成，同时保留对实际提交文本变更的审查，并避免把未分析的二进制误报为已完成。

## 后果

- `incomplete` 结果不再因补充上下文缺失产生；目前仅用于存在非文本审查项。
- 结果报告不显示必需依赖、补充上下文或二进制文件清单。
- 旧 CLI JSON 中的 `context_requests` 及 `coverage.dependencies`、`coverage.context`、`coverage.binary` 字段不再提供。
- 对未选择文件调用关系的判断只能依赖已提供代码，模型不再请求额外文件。
