# 提交前审查允许补充范围内的 BASE 上下文

提交前审查需要判断变更与相关代码的关系，仅提供提交选择的差异可能不足以形成证据。因此独立 CLI 与后续插件共用不依赖 VS Code 的审查核心，以提交选择为审查目标，允许模型最多请求一次管理范围内的文本上下文：所选文件使用本次工作副本版本，未选文件只提供 BASE，不读取其未提交修改，也不跨工作副本、externals 或管理范围。相较于只返回证据不足，这会向模型服务提供部分未选择文件的已提交内容，但能在不假设额外变更会一起提交的前提下完成审查；这是 ADR 0001 输入边界针对提交前审查的明确扩展，提交信息草稿仍遵循原有输入边界。用户已在设计访谈中确认。
