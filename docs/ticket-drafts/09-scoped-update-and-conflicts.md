# 09: 更新管理范围并展示冲突

**What to build:** 用户在打开目录范围内更新工作副本，看到同步结果或冲突；随后可用现有工具解决并标记冲突，刷新后继续选择提交。

**Blocked by:** 04 — 选择并提交已修改文件。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 更新遵守管理范围，不因工作副本根在更高层而更新未打开区域。
- [ ] 更新与其他写操作互斥，成功或失败均准确刷新并提示。
- [ ] 冲突在列表中呈现，存在冲突的提交范围被阻止提交。
- [ ] 外部解决并标记后刷新可继续提交；不自动解决冲突或更新后重试提交。
- [ ] 认证、证书和网络失败提供准确原因，不绕过证书检查。
- [ ] 使用两个隔离工作副本通过公开入口验证同步、未打开范围保留、冲突、外部解决和失败状态。
