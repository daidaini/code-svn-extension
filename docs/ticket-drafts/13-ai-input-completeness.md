# 13: 让 AI 完整处理新增、属性和二进制变更

**What to build:** 用户对包含新增文件、目录依赖、属性或二进制的提交选择生成草稿时，输入准确表达全部所选变更；文本超限则得到缩小选择的提示。

**Blocked by:** 05 — 添加新文件并提交必需父目录；06 — 提交目录属性与整体目录删除；12 — 为选中文本变更生成 AI 草稿。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 新增文本及其明确依赖进入本次输入，未跟踪文件和未选兄弟内容不进入请求。
- [ ] 文件和目录属性差异被包含，不能只提取文本 hunk。
- [ ] 整体目录删除和其他所选状态得到准确表达，不把无文本差异解释为无变化。
- [ ] 二进制仅提供路径和变更类型，并向用户明确说明未分析内容。
- [ ] 文本输入超限时停止请求并提示缩小选择，不静默截断、不分段多次总结。
- [ ] 通过公开生成流程和可控服务验证请求完整性及范围；混合输入、超限和二进制限制均验证用户可见结果。
