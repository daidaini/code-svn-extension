# 11: 查看对象历史差异并追溯旧路径

**What to build:** 用户选择历史修订，看到当前文件或目录相关的变更路径，并在差异编辑器查看这次提交前后内容；SVN 已记录的复制或移动前历史也可追溯。

**Blocked by:** 03 — 在编辑器中审阅本地差异；10 — 查询服务器最新文件与目录历史。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 点击修订显示所查询对象相关的变更列表，不混入同一修订的无关对象。
- [ ] 使用已有差异展示入口查看提交前后文本，属性变化也可审阅；二进制限制明确说明。
- [ ] 正确处理历史新增和删除，不错误使用当前工作副本内容替代历史内容。
- [ ] 沿 SVN 保留的复制、移动和重命名关系追溯旧路径，历史内容对应实际路径与修订。
- [ ] 查询失败、取消与空结果有明确区分，不新增复杂筛选。
- [ ] 公开流程验证无关路径过滤、提交前后内容、跨路径历史及分页衔接；历史夹具由 SVN 建立，不依赖插件移动提交票。
