# 01: 在打开目录内查看 SVN 变更

**What to build:** 用户安装并启动扩展，打开一个 SVN 目录后，在中文源代码管理面板看到该管理范围内的真实变更，可自动或手动刷新；缺少 SVN 时得到配置指引。这是从扩展激活到 CLI 调用、视图及公开命令集成验证的第一条完整路径。

**Blocked by:** None (can start immediately).

**Status:** implemented — 用户已确认任务顺序；本地实现与验证完成，尚未单独发布 GitHub 任务。验证见 [task-01-validation.md](../task-01-validation.md)。WSL 实际验收留待任务 15。

- [x] 用户可配置 SVN 可执行文件；执行位置与工作区所在环境一致。
- [x] 打开完整工作副本或一个子目录时，只展示打开目录内的文件、目录及属性状态，不自动扩大到工作副本根的兄弟目录。
- [x] 未跟踪文件有明确状态；嵌套工作副本和 externals 不被自动接管。
- [x] 自动刷新和手动刷新均可观察到变更，冲突状态正确展示。
- [x] 中文和空格路径在扩展进程中得到正确处理，查询失败不显示为无变更。
- [x] 通过扩展公开命令及用户可见列表进行隔离仓库集成验证；提供可调试、可构建的最小扩展，尚不宣称完整首版交付。
