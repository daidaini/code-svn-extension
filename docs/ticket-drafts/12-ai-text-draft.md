# 12: 为选中文本变更生成 AI 草稿

**What to build:** 用户配置一家模型服务，在待提交的普通文本修改上点击生成，得到可审阅、修改的中文提交信息草稿，再手动提交。本票交付内容不变的正常生成流程；属性、二进制、输入超限与完整过期生命周期由后续票扩展，未覆盖输入须明确阻止而非遗漏后发送。

**Blocked by:** 03 — 在编辑器中审阅本地差异；04 — 选择并提交已修改文件。

**Status:** implemented — 普通文本修改的正常生成流程已实现并经公开入口验证；真实模型服务兼容性未验证，
属性、二进制、输入超限与完整过期生命周期由任务 13、14 扩展。尚未单独发布到 tracker。

验证结果见 [任务 12 验证记录](../task-12-validation.md)。

- [x] 配置一套有效的 API Base URL、模型与 API Key，密钥使用 SecretStorage。
- [x] AI 与提交使用同一提交选择，空选择不能请求，未保存内容先提示保存或取消。
- [x] 单次非流式 Chat Completions 请求只发送选中文本差异，返回中文短标题及必要要点。
- [x] 已有输入替换前确认，用户可修改草稿，生成不自动提交。
- [x] 支持取消、超时和服务错误，保留原输入，由用户手动重试。
- [x] 未完成后续扩展前，对尚不支持的输入明确拒绝；请求期间已检测到选择变化时不填入结果，不把正常流程通过当作完整 AI 验收。
- [ ] 通过公开入口及可控服务捕获请求验证选择边界、生成、覆盖取消、保存取消和错误结果；配置真实服务后可演示完整文本生成流程。
      可控服务部分已全部验证；真实厂商服务的兼容性与生成结果尚未验证（需要使用者提供配置）。
