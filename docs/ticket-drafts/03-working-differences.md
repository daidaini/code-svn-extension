# 03: 在编辑器中审阅本地差异

**What to build:** 用户从变更列表查看本地文件内容和属性变化；目录属性与二进制限制也有清楚的呈现，可在提交前理解变更。

**Blocked by:** 01 — 在打开目录内查看 SVN 变更。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 文本文件的本地变化在 VS Code 差异编辑器中正确展示。
- [ ] 文件和目录属性变化能够查看，不能只保留文本 hunk。
- [ ] 新增和删除文本的差异按实际状态呈现；未跟踪文件不伪装成已有 SVN diff。
- [ ] 二进制无文本差异时明确说明内容不可分析，不能显示为没有变更。
- [ ] 查看动作遵守管理范围，读取失败显示可操作原因。
- [ ] 公开入口集成验证文本、属性、新增、删除、二进制和中文路径的用户可见结果。
