# 04: 选择并提交已修改文件

**What to build:** 用户把已修改的版本控制文件加入待提交，输入信息后提交，确认仓库中只包含选中的完整文件。空选择、未保存内容、冲突和失败均有明确处理。这张票先交付普通修改文件流程，新增及目录特殊语义由后续票扩展。

**Blocked by:** 01 — 在打开目录内查看 SVN 变更。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 新发现变更默认未选中，可加入或移出待提交；空选择不能提交。
- [ ] 按完整文件提交，不使用 Git 暂存区语义，不夹带未选修改。
- [ ] 未保存的选中文件提示保存；取消则停止操作。提交范围内存在冲突时阻止提交。
- [ ] 同一工作副本写操作互斥；使用当前环境认证，访问失败提供同环境配置指引，不自动忽略证书错误。
- [ ] 失败保留提交选择和输入；确认产生修订并刷新后才清理已提交项。零退出码但没有修订不显示成功。
- [ ] 不自动重试或强制中断提交，不主动跨窗口重启保存提交选择。
- [ ] 通过公开命令验证真实仓库结果、未选修改保留、保存取消、冲突阻止、互斥、失败恢复及无修订结果；先前已有选择所不支持的变更不被错误提交。
