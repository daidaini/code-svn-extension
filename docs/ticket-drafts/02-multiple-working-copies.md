# 02: 在多根工作区分别管理工作副本

**What to build:** 用户在同一个窗口打开多个目录时，每个工作副本单独展示；同一工作副本的打开目录合并去重，其管理范围为这些目录的并集。

**Blocked by:** 01 — 在打开目录内查看 SVN 变更。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 不同工作副本显示为独立管理项，不共享提交选择或提交输入。
- [ ] 同一工作副本的重叠目录合并去重，互不包含的打开目录也归属同一工作副本。
- [ ] 管理范围取打开目录并集，不包含未打开的其他区域；非 SVN 目录不出现 SVN 管理项。
- [ ] 用户增删工作区目录后，视图和管理范围随之刷新。
- [ ] 通过公开命令和可见列表验证多工作副本、重叠目录、范围变化和混合工作区。
