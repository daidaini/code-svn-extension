# 02: 在多根工作区分别管理工作副本

**What to build:** 用户在同一个窗口打开多个目录时，每个工作副本单独展示；同一工作副本的打开目录合并去重，其管理范围为这些目录的并集。

**Blocked by:** 01 — 在打开目录内查看 SVN 变更。

**Status:** implemented — 用户确认继续任务 02；本地实现与验证完成，尚未单独发布 GitHub 任务。验证见 [task-02-validation.md](../task-02-validation.md)。

- [x] 不同工作副本显示为独立管理项，不共享提交选择或提交输入。
- [x] 同一工作副本的重叠目录合并去重，互不包含的打开目录也归属同一工作副本。
- [x] 管理范围取打开目录并集，不包含未打开的其他区域；非 SVN 目录不出现 SVN 管理项。
- [x] 用户增删工作区目录后，视图和管理范围随之刷新。
- [x] 通过公开命令和可见列表验证多工作副本、重叠目录、范围变化和混合工作区。

每个工作副本持有独立 SourceControl 对象及其输入框，输入框当前隐藏；提交选择与提交输入交互将在任务 04 实现并验证。
