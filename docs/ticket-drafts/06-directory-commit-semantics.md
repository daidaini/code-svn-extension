# 06: 提交目录属性与整体目录删除

**What to build:** 用户选择目录属性变更或整体目录删除时，插件准确展示操作范围，并执行对应提交；目录属性不能夹带子文件，目录删除不能伪装为逐子文件操作。

**Blocked by:** 03 — 在编辑器中审阅本地差异；04 — 选择并提交已修改文件。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 用户能审阅并选择目录属性，单独提交属性后未选子文件仍保持本地修改。
- [ ] 目录删除以整个子树为一个操作呈现，明确展示受影响子项。
- [ ] 不提供误导性的逐子文件拆分目录删除；必须尊重管理范围及未接管对象边界。
- [ ] 依赖或完整操作范围超出管理范围时停止，不能悄悄扩大目标。
- [ ] 保持保存、冲突、互斥、失败保留及真实成功判断规则。
- [ ] 通过公开入口及仓库结果验证目录属性隔离、整体树删除、边界阻止和无修订的提交结果。
