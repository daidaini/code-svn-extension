# 14: 阻止过期 AI 结果进入提交

**What to build:** 用户在 AI 生成期间或之后改变选择、文件内容或属性时，插件识别草稿过期，并按明确规则停止填入或提示重新生成及确认继续使用。

**Blocked by:** 12 — 为选中文本变更生成 AI 草稿。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 请求期间提交选择或相关内容变化时，返回结果不填入输入框并提示重新生成，包括外部保存和属性变化。
- [ ] 已生成草稿的相关内容变化时提示过期，重新生成或明确确认后才继续使用该草稿。
- [ ] 未保存的编辑变化也被正确处理，不能仅依赖进程退出或单次列表刷新。
- [ ] 确认替换已有输入期间再次发生变化时，不把过期结果误认为当前结果。
- [ ] 取消或先前请求的延迟响应不能覆盖较新的用户输入或生成结果。
- [ ] 通过公开入口及可控延迟响应验证选择改变、内容改变、属性改变、已有输入、取消与提交前确认，不依赖私有函数或内部调用次数。
- [ ] 通用过期行为不依赖特殊输入票先完成，完整首版组合在最终交付票中复验。
