# 05: 添加新文件并提交必需父目录

**What to build:** 用户显式添加未跟踪文件，再把新增项加入待提交。需要新增父目录时，插件展示提交依赖，能够提交选定新文件而保留未选兄弟变更。

**Blocked by:** 04 — 选择并提交已修改文件。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 添加与提交为两个明确操作；未跟踪文件不能直接进入待提交或 AI 输入。
- [ ] 添加操作遵守管理范围及工作副本写操作互斥，成功后刷新。
- [ ] 新文件所需新增父目录明确展示为必需提交依赖。
- [ ] 显式提交选择和依赖，不递归夹带未选兄弟文件。
- [ ] 依赖超出管理范围时阻止操作并解释原因。
- [ ] 新增文本通过已有差异入口正确显示；失败保留选择和输入。
- [ ] 公开流程验证从未跟踪到添加、审阅、选择及真实提交，包括多层父目录和未选兄弟项。
