# 07: 审阅并提交 SVN 已记录的移动与复制

**What to build:** 用户通过终端执行 SVN 移动、重命名或复制后，在变更列表看到正确关系，并能够审阅、选择及提交完整操作。

**Blocked by:** 05 — 添加新文件并提交必需父目录；06 — 提交目录属性与整体目录删除。

**Status:** draft — 待用户确认拆分及 tracker 配置；尚未发布。

- [ ] 文件和目录已记录的复制、移动及重命名关系正确呈现。
- [ ] 提交保留 SVN 记录的关系；相关源、目标及必需父目录作为明确展示的操作及依赖处理。
- [ ] 不夹带未选无关变更，相关范围超出管理范围时阻止操作并说明原因。
- [ ] 普通资源管理器重命名不自动被推断或转换为 SVN 移动。
- [ ] 不新增专用移动、重命名或复制操作入口。
- [ ] 公开入口验证文件和目录的关系呈现、审阅、真实提交及无关变更保留。
