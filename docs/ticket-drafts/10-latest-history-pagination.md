# 10: 查询服务器最新文件与目录历史

**What to build:** 用户从文件或目录右键打开历史，看到服务器最新记录，按每批 50 条加载更早记录；本地未更新不影响查看最新历史。

**Blocked by:** 01 — 在打开目录内查看 SVN 变更。

**Status:** implemented — 已按用户确认范围实现并验证；尚未单独发布到 tracker。

验证结果见 [任务 10 验证记录](../task-10-validation.md)。

- [x] 文件和目录右键提供入口，目录查询包含子项。
- [x] 列表显示修订号、作者、时间和提交信息，最新优先，每批 50 条并支持加载更多。
- [x] 显式查询服务器最新历史，不依赖本地默认修订范围。
- [x] 分页不重复或遗漏，查询可取消；失败不显示为空历史。
- [x] 提供准确的认证、证书及网络失败指引，不自动忽略证书错误。
- [x] 公开入口验证超过 50 条历史、本地落后服务器、目录子项、取消和失败；无需等待插件提交功能，历史由隔离仓库夹具建立。
