# 首版实施与验收

依据 [首版设计](./design.md)。当前只完成设计和部分 SVN 行为核对；插件代码、安装包和平台验收尚未开始。整体方案确认后按以下顺序实现。

用户授权的真实验证工作副本为 `E:\WorkCode\BizDocs`，用于只读识别、状态、差异和历史查询；写操作使用隔离测试仓库。已有 CLI 验证结果见 [svn-validation.md](./svn-validation.md)，不据此勾选插件验收项。

## 实施顺序

1. **插件骨架与工作副本识别**：配置 TypeScript、扩展入口和开发调试，接入当前环境 SVN，展示工作副本和打开范围。验证完整目录、子目录、多根工作区、重叠目录、非 SVN 目录和缺少 SVN 的场景。
2. **变更与选择提交**：实现状态刷新、差异、添加、撤销、更新、待提交选择、目录依赖和提交。用临时仓库验证没有夹带未选变更，覆盖目录属性、整个子树删除、冲突、未保存文件和失败状态保留。
3. **文件和目录历史**：实现右键入口、每批 50 条、加载更多、服务器最新记录、复制或移动历史和修订差异。用具有多个修订及跨路径历史的测试仓库验证列表与内容。
4. **AI 提交信息**：配置单一模型服务及 SecretStorage，接入非流式 Chat Completions，绑定提交选择、差异输入和草稿生命周期。先用可控服务验证取消、失败、超限和过期行为，再以使用者配置的一家厂商验收真实生成。
5. **打包与双环境验收**：生成 .vsix 和中文说明，在 Windows 与 VS Code WSL 工作区分别验证实际安装、SVN 行为与 AI 入口。记录通过、失败和未验证项，完成条件是两个目标环境均有实际通过证据。

## 验收清单

所有项目目前均未标记为通过；前期 CLI 探针只提供实现依据。

### 环境与项目识别

- [ ] Windows 本地安装 .vsix 可运行并调用 Windows SVN。
- [ ] VS Code WSL 安装 .vsix 可运行并调用 Linux SVN。
- [ ] SVN 路径配置有效；未安装或不可执行时提示可操作的原因。
- [ ] 完整工作副本、打开子目录及多根工作区正确展示。
- [ ] 插件进程正确处理中文、空格路径及编码；独立复测 BizDocs 中已发现的绝对中文路径调用失败场景。
- [ ] 同一工作副本重叠目录合并去重，打开范围之外的变更不被操作。
- [ ] 非 SVN 目录不展示管理项，嵌套工作副本及 externals 不被自动接管。

### 变更与提交

- [ ] 文件和目录状态、文本差异与属性差异正确展示。
- [ ] 未跟踪文件先添加，新增变更默认未选中，空选择不能提交或生成 AI。
- [ ] 同一份待提交选择驱动提交与 AI，文件按整体提交。
- [ ] 提交一个文件不会夹带未选文件、同目录修改或属性变化。
- [ ] 新增父目录依赖明确展示，超出管理范围时阻止操作。
- [ ] 删除目录按整个子树展示和提交，不提供误导性的逐子文件删除提交。
- [ ] 已通过 SVN 执行的移动、重命名和复制正确展示；不自动推断普通重命名。
- [ ] 选中未保存文件时提示保存，取消则停止；提交范围有冲突时阻止提交。
- [ ] 撤销明确确认范围；不删除未跟踪文件，取消添加时保留文件。
- [ ] 更新及其他写操作遵守管理范围、同一工作副本互斥并正确刷新。
- [ ] 失败保留选择和输入，不自动重试提交；真实提交成功才清理已提交项。
- [ ] 退出码为零但没有产生修订的情况不会显示为提交成功。
- [ ] 缺少认证或证书信任时引导同环境终端配置，不自动忽略证书错误。

### 历史

- [ ] 文件和目录右键可打开历史，显示修订号、作者、时间和提交信息。
- [ ] 最新优先，每批 50 条，加载更多不重复或遗漏修订。
- [ ] 本地工作副本未更新时也能查询服务器最新记录。
- [ ] 文件和目录历史差异只展示所查询对象的变化，不混入无关路径。
- [ ] 复制、移动及重命名前的旧路径历史可追溯，差异内容对应所选提交前后。
- [ ] 历史加载可取消，错误不被显示为空历史或查询成功。

### AI

- [ ] 可配置 API Base URL、模型与 SecretStorage 中的 API Key，一次非流式请求返回中文草稿。
- [ ] AI 输入只包括本次选择及依赖的变更，包含属性差异，不夹带未选文件内容。
- [ ] 二进制仅提供路径和变更类型，用户明确知道未分析内容。
- [ ] 文本差异超限时停止并提示，不截断或分段多次请求。
- [ ] 已有提交信息替换前确认；生成结果不自动提交。
- [ ] 请求期间选择或相关内容变化，返回结果不填入输入框。
- [ ] 生成后相关内容变化时提示过期，重新生成或明确确认后才能继续使用。
- [ ] 取消、超时、服务错误保留原输入，由用户手动重试。
- [ ] 使用配置的一家真实厂商完成兼容性验证；模拟服务通过不等于真实服务通过。

### 交付

- [ ] 源码、构建与调试说明、中文使用说明齐全。
- [ ] .vsix 可安装，Windows 与 WSL 分别有操作验收记录。
- [ ] 最终报告明确列出真实通过、失败、未验证的场景，不将缺少测试条件视为通过。
