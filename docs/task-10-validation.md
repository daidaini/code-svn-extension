# 任务 10 验证记录

## 实现范围

文件和目录右键菜单新增「SVN：查看历史」，源代码管理资源行也提供同一入口。
历史查询直接访问服务器：先用工作副本元数据取得对象的仓库地址，再以 `HEAD:1` 查询，
不依赖本地修订号。`svn log` 默认沿复制和移动关系追溯旧路径。
目录查询包含子项。

列表使用 VS Code 快速选择，每行显示修订号、作者、时间和提交信息，最新优先。
每批 50 条，末尾「加载更早的 50 条」行请求下一批。下一批起点为已显示最后一条修订号减一，
通过多取一条判断是否还有更早记录，避免重复和遗漏。

失败分为四类，均附带原始 SVN 错误并写入查询日志：

- 认证失败（E170001、E215004）：请在工作区所在环境的终端完成 SVN 登录。
- 证书校验失败（E230001）：请在同一环境信任证书，插件不忽略证书错误。
- 无法连接服务器（E170013、E175002）：检查网络、代理及仓库地址。
- 不在版本控制中（W155010、E155007、E155010、E200009）或服务器上找不到路径（E160013）。

首批失败或首批为空时不显示空列表；后续批次失败保留已加载记录，加载更早的行仍可重试。
关闭列表即取消正在进行的查询，并终止 SVN 进程。历史查询只读，不加写锁。
