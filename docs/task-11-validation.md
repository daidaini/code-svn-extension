# 任务 11 验证记录

日期：2026-10-13。

## 实现范围

历史列表中点击修订，打开该修订中影响所查询对象的变化列表。选择变化项后，
通过 VS Code 差异编辑器查看这次提交前后的文本；属性变化在属性差异中展示。

**修订变化过滤。** `svn log -v` 会列出同一修订中的全部路径，包括无关文件。插件只保留两类路径：

- 该修订中对象自身所在的路径（`svn info -r N 对象@HEAD` 通过 SVN 复制历史取得）。
- 对象在前一修订的路径被删除的记录，即移动的源端。

**历史内容。** 前后内容分别用 `svn cat` 和 `svn proplist` 按仓库路径与修订读取，不读取工作副本。
复制或移动的前侧使用复制来源路径及复制修订，与 SVN 自身显示的差异一致。
二进制内容只给出路径和变化类型，并提示未分析文本内容。

**界面。** 点击修订后，历史列表关闭，改为显示变化列表；取消变化列表会终止查询。
修订变化查询失败时显示原始错误及对应指引，不显示为空列表。
历史差异使用只读的修订内容文档，与本地差异的 `codeSvn` 文档隔离。

此前任务 10 的 `readObjectUrl` 改为 `readObjectLocation`，同时返回仓库根，供内容地址拼接。
