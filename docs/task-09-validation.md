# 任务 09 验证记录

日期：2026-10-13。审查基准：`a332c00`。

## 实现范围

新增「SVN：更新管理范围」公开命令与 SCM 标题栏更新按钮。
多工作副本时明确选择一个副本；更新目标为该副本当前打开目录的并集，
合并重叠目标，不因工作副本根在更高层而更新未打开区域。
调用 SVN 时使用参数数组、相对路径及 peg 分隔符，支持中文、空格和 `@` 路径；
使用 `--non-interactive --ignore-externals --accept postpone`，不扩展稀疏检出深度，
不自动接管 externals 或嵌套工作副本，不自动解决冲突或重试提交，也不绕过证书检查。

更新与现有提交、添加、撤销共用工作副本写锁。
更新范围有未保存内容时停止；更新不设置强制超时，避免中断已部分应用的写操作。
成功或失败后均刷新实际状态，并保留提交信息和仍有变更的选择；
只有完整刷新确认已干净且仍在当前管理范围内的选定路径才移出待提交。
刷新失败时保留旧列表并明确说明不能确认最新状态，不把失败当成同步完成。
SVN 原始同步结果及失败原因记录在现有输出通道。

文本、属性和树冲突沿用 SVN 状态解析与提交验证。
冲突资源行有警告图标及提示；已选冲突和依赖冲突分别在对应分组标记「含冲突」，
不会被「待提交」分组隐藏。用户通过已有工具解决并用 SVN 标记后刷新，再手动提交。
不新增合并界面或自动解决入口。
